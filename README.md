# ContractGuard AI



### AI-Powered Software Contract Review & Compliance Platform

A smart platform for creating, validating, analyzing, and simplifying software contracts using AI, OCL constraints, and Egyptian legal regulations.

---

## 📌 Overview

ContractGuard AI is a graduation project designed to help software companies and clients create legally compliant software contracts with the assistance of Artificial Intelligence.

The system combines:
- Rule-based contract validation using OCL (Object Constraint Language)
- AI-powered legal clause analysis
- Egyptian law compliance checking
- Contract simplification using LLMs
- Multi-role management platform for companies and clients

The goal is to reduce legal risks, improve contract quality, and simplify legal understanding for non-legal users.

---

## 🚀 Features

### 🔹 Contract Management
- Create and manage software contracts
- Edit and store contract versions
- Upload and review agreements

### 🔹 AI Legal Analysis
- Detect risky or invalid clauses
- Analyze compliance with Egyptian software laws
- Suggest improvements for clauses

### 🔹 OCL Rule Validation
- Validate contracts against predefined business and legal rules
- Ensure structural and logical correctness

### 🔹 Clause Simplification
- Convert complex legal text into understandable language
- Improve readability for clients and developers

### 🔹 Multi-Role System
- Admin
- Software Company
- Project Manager
- Client

### 🔹 Security & Authentication
- Secure login system
- Role-based access control
